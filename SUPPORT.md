# Support

This is sample code published alongside a blog post. It is maintained on a
best-effort basis by its authors and is **not** covered by AWS Support.

- **A problem with the sample** — open an issue in this repository. Please
  include your Terraform version, `aws`/`awscc` provider versions, the Region,
  and the full error output.
- **A question about Amazon Connect Customer itself** — see the
  [Amazon Connect Administrator Guide](https://docs.aws.amazon.com/connect/latest/adminguide/)
  or [AWS re:Post](https://repost.aws/).
- **A security issue** — see [SECURITY.md](SECURITY.md). Do not open a public
  issue.
